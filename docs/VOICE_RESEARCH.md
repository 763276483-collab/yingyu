# 角色语音方案调研

核对日期：2026-11-24。用户已明确优先“自然、有角色感的云端语音”。当前选择是先实现 MiniMax 的手动朗读，保留系统 TTS，后续比较 CosyVoice；本地模型作为离线扩展方向。

## 云端方案

| 方案 | 已核对能力 | 在本工程中的位置 |
| --- | --- | --- |
| MiniMax Speech | 文本生成音频、按 voice_id 选择声音、语速参数，支持完整音频或流式输出 | 已编写首个适配器，使用非流式 MP3，待真实账号联调 |
| 阿里云百炼 CosyVoice / Qwen TTS | 预设声音、自定义音色相关能力、多种合成方式，具体能力依模型而定 | 候选第二提供商，尚未实现 |
| Android 系统 TTS | 使用设备安装的语音引擎与音色 | 已编写，可让用户主动选择 |

MiniMax 默认使用官方同步语音接口的完整 URL，模型暂定 speech-2.8-hd；也可填写账号支持的 turbo 模型。音色选择以控制台试听与可用音色 ID 为准，示例 ID 只用于初次接入，不代表已选定最终角色声音。接口和模型选择依据 [MiniMax 同步语音合成官方文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)。

阿里云可按系统音色、音色复刻或音色设计选择服务。不同地域和模型的可用功能需要按账号核对，不能把一套参数直接复制到全部模型。本工程后续将为其增加独立适配器，参见 [百炼语音合成概述](https://help.aliyun.com/zh/model-studio/tts-model)。

暂不把价格写死，也未进行主观音质排名。接入前应用同一批台词试听，比较角色匹配度、中文自然度、首音频延迟、成功率和实际账单，再确定默认服务。

## 手机离线方案

sherpa-onnx 是推理与部署框架，不是单个声音模型。官方提供 Android 朗读应用和系统 TTS 引擎 APK，可以先安装试听，再决定是否把原生库与模型直接集成到应用中。[官方 Android TTS 引擎下载与说明](https://k2-fsa.github.io/sherpa/onnx/tts/apk-engine-cn.html)

| 本地模型 | 官方可核对信息 | 本项目评估方向 |
| --- | --- | --- |
| VITS MeloTTS zh_en | 中文与英文，页面列出单音色和约 163 MB 模型文件 | 中文离线入门候选，先测试单音色是否满足角色风格 |
| 其他中文 VITS | 多种中文音色模型，部分模型文件约 115–117 MB | 为每个候选核对音质、音色授权与运行速度 |
| Kokoro 多语种 | sherpa 提供支持中英的模型，含量化下载；v1.0 示例 model.onnx 约 310 MB，另有声音与词典文件 | 多音色离线候选，优先评估量化版本和中文效果 |

模型资料：[sherpa VITS 模型列表](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html)、[sherpa Kokoro 模型说明](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/kokoro.html)。表中的数字是官方列出的模型文件大小，不是 APK 大小，也不是运行内存；不同版本和量化方式不能直接混用。

这些资料能证明存在 Android 部署路线，不能证明用户手机已经可以实时运行。手机型号、芯片、可用内存、温控和电量策略仍未知，不能承诺固定速度或最低内存。代码框架与模型权重也可能适用不同许可，选定分发包时逐项核对。

## 建议的实际验证

1. 先在 MiniMax 控制台试听多个中文声音，确定角色音色 ID，使用同一批台词测试 HD 与 turbo 的体验。
2. 配置用户自己的 Key，验证试听、朗读、停止、快速切换消息、断网和余额不足等情况。
3. 对比百炼候选音色，按体验和实际费用决定是否接第二家。
4. 离线需求出现后，补充手机型号、Android 版本、内存，选择匹配架构的官方 sherpa 引擎 APK，先独立试听，再切换系统 TTS 到该引擎测试本应用。
5. 只有确认某个模型值得保留，才集成下载管理、模型校验、缓存、原生库与后台推理，避免初版安装包提前携带大量权重。

测试应记录首音频时间、合成耗时、音频时长、RTF = 合成秒数 / 音频秒数、峰值内存、连续使用后的发热和耗电。RTF 小于 1 表示整体合成速度快于音频播放速度，但不等于首音频响应快。

系统离线筛选使用 Android Voice.isNetworkConnectionRequired；它是引擎声明，实际离线效果还要安装音色后用飞行模式验证。[Android Voice 官方接口](https://developer.android.com/reference/android/speech/tts/Voice)

当前语音指文字转语音，不包含麦克风输入、语音识别、实时语音通话、自动情绪判定或声音克隆。它们都可以追加为独立需求。
