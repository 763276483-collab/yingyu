## 本轮实现约定

以下是可调整的工程选择，不表示用户已逐项确认。

- 暂用“角色聊”作为名称，中文界面，最低 Android 8.0。
- 用户自己填写聊天与语音服务 Key，应用暂不设置账号系统或自建后端。
- 每段对话保存创建时的人物卡快照。修改人物卡影响新对话，已有对话维持原设定。
- 先做完整文本回复、点击朗读，不自动付费合成；流式文字和边生成边说话排到下一阶段。
- 首个云端语音提供商选 MiniMax，CosyVoice 为下一候选；并非要求用户必须购买其中某个平台。
- 一次只处理一条聊天生成任务。停止、失败或进程退出后保留末尾用户消息，可重试或撤回。
- 每次发送最近 N 轮用户发言及其回复，默认 12 轮。它是轮数限制，尚未做模型 tokenizer 的精确 token 预算。
- 数据只保存在应用私有目录，尚无导出或跨设备同步。卸载会删除数据，应先完成备份功能再作为长期使用版本。
- 聊天外观先采用全局设置，支持静态壁纸；默认低浓度透色层与轻度背景模糊。通透程度、模糊强度与文字深浅可调；不声称已经实现苹果系统的动态光学折射。

## 原型验收标准

1. 创建包含五项内容的人物卡，重启后仍存在；编辑内容能保存。
2. 保存合法接口和密钥后，服务商能收到包含角色设定与历史的请求，回复展示在正确对话中。
3. 两个人物的对话相互独立；同一人物可开始新对话，并切换查看以前的对话。
4. 修改人物卡后创建新对话，新设定生效，旧对话的人物快照保持原值。
5. 断网、鉴权失败、限流时显示明确错误；重试不重复插入用户消息。
6. 点击停止能取消本机等待；停止不保证撤销服务商已受理的任务或计费。
7. 云端语音使用独立 Key 与角色音色，合成后能播放、停止，连续点击不叠加播放。
8. 未配置云端语音 Key 时保留聊天功能，朗读显示配置提示；不擅自切换服务商。
9. 选择系统离线音色后，不选择被引擎标为需联网的音色；飞行模式下仍需验证实际可用性。
10. 数据损坏或版本过新时停止写入，保留原文件；密钥不出现在明文数据、源码或日志中。
11. 原壁纸在气泡外清晰可见，气泡内为同一位置的模糊壁纸；滚动、横竖屏和键盘弹出后不能出现取样错位或模糊文字。
12. 壁纸与外观保存后重启恢复；旧版记录迁移前保留原始副本，迁移失败不覆盖原记录。深浅壁纸都可通过文字深浅与玻璃参数调到可读状态。

13. 错误详情显示 HTTP 状态、模型与服务端说明，已知密钥脱敏，可手动复制；不能把 400 当成密钥错误、把 402 混成模型地址错误。
14. 测试连接只读取模型列表；可以选择返回的模型再保存，不自动更换模型或重复发起生成请求。开场白保留在界面与上下文中，发送的对话历史从用户发言开始。

Android 编译与 36 项单元测试已通过。用户截图验证了旧版聊天界面和失败状态；完整生成、语音、迁移等端到端体验仍待真机确认。后续功能继续追加编号、状态、验收方式及对应改动日志。
