# 映语：命名与图标方案

日期：2026-11-24。用户已接受“映语”作为程序名称，并要求生成几个图标供选择。原工作名为“角色聊”；包名与数据文件名不因品牌名称改变而迁移。

## 设计方向

呼应人物对话、角色声音和通透玻璃界面。颜色沿用靛蓝、淡紫、冰蓝；以简洁气泡为主体，控制反光与细节，保持桌面小尺寸辨识度。图标内不加文字，名称由系统桌面显示。

本轮生成三个独立的方形候选：

| 文件标识 | 中文名称 | 设计 |
| --- | --- | --- |
| 01-overlapping-bubbles | 叠映气泡 | 深靛蓝背景，冰蓝/淡紫双层玻璃气泡，交叠处一颗小四角星 |
| 02-starlight-conversation | 星光对话 | 浅淡紫背景，单个紫色玻璃气泡包住明亮四角星 |
| 03-voice-glass | 声纹玻璃 | 午夜蓝背景，青紫玻璃气泡中有三条圆润声纹 |

## 生成与保存

使用内置 image_gen 工具与 imagegen 技能，一款一条独立提示词，不调用用户 API 或读取其 Key。完整最终提示词和工具设置保存于 `../../Yingyu-Icon-Concepts/prompts.json`。三款已全部生成并复制到同目录，文件名为表格标识加 `.png`，每张为 1254×1254 PNG；原文件未删除，尺寸、字节数与 SHA-256 见同目录 manifest.json。

已逐张目视检查：均为独立图标，气泡、星光或三条声纹主题符合对应方案，无嵌入文字。尚未制作 Android 多尺寸/adaptive 图标或在桌面实际验证裁剪与小尺寸效果。本轮仅设计及文档更新，不运行无关 Android 测试。

当前仅为候选设计。最终图标待用户选择；未替换 APK launcher 图标、未修改显示名称、未重新编译或安装 APK。后续选定后再制作 Android 图标资源并验证桌面显示。

## 后续接入原则

保留现有 applicationId `com.rolechat.app`、调试签名、私有目录和数据格式，避免品牌更名导致升级链或记录丢失。后续更新显示名称时统一检查 Manifest 与应用内标题；候选预览不等于启动图标已接入。适配系统图标裁剪时检查主体和气泡尾巴是否完整、深浅背景与缩小后的可读性。
