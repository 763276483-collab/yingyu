# 当前状态与后续步骤

更新时间：2026-11-24。

当前版本：**映语 0.3.8**（`versionCode=15`，`com.rolechat.app`，沿用原调试签名与数据格式 v2）。已修复前文收起的列表状态/动画耦合，首页、编辑与接口设置统一夜间玻璃风格，补齐 DeepSeek/MiniMax 的接入与模型选择说明和官方入口。55 项 JUnit、构建、签名、对齐与结构检查通过；华为手机普通比例 6 轮、宽屏模拟 3 轮切换通过，手机已返回首页。方案与验证见 NIGHT_AND_HISTORY_FIX、VALIDATION 和 HANDOFF。

## 下一阶段优先顺序

1. **用户的实际平板/折叠屏复验**：重点看连续收起/展开、夜间阅读和长文布局；本次宽屏尺寸模拟不能代替真实折叠设备。
2. **组合场景回归**：长回复正在打字时切换模式、软键盘弹出、旋转/开合、多角色/多历史切换、断网/停止/重试、系统 TTS 离线路径。已有 DeepSeek/MiniMax 成功记录保留，本轮未新增付费生成或语音调用。
3. **长期使用能力**：补齐备份导出/导入（默认排除 Key）、人物卡导入/导出、Room 迁移，再按用户需求推进消息编辑与重生成、真正 SSE 流式输出与边生成边朗读。

## 可由用户后续补充

- 软件名称“映语”和正式图标已接入；是否自用或考虑发布仍可补充。
- 常用聊天供应商、接口协议与模型名称；不需要将 Key 发送给助手。
- 角色声音偏好，例如青年男声、成熟女声、活泼或温柔，以及是否需要多个角色不同音色。
- 朗读是一直手动点击，还是以后需要自动播放、边生成边说话或语音通话。
- 若继续研究离线语音：手机型号、Android 版本、内存与可用存储。
