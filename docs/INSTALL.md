# 手机上安装和首次使用

源码 ZIP 用于继续开发，不能直接安装到手机。手机需要扩展名为 `.apk` 的安装包。

## 安装步骤

1. 在电脑上下载交付的 APK，通过 USB、网盘或文件传输发到 Android 手机上。使用“文件”方式发送，保留 `.apk` 扩展名。
2. 在手机文件管理器中找到 APK，点击安装。
3. 若系统提示当前来源没有安装权限，按提示给本次使用的文件管理器或浏览器允许安装，然后返回继续。不同品牌的入口名称可能不同。
4. 安装后打开“映语”。需要 Android 8.0 或更新版本；不支持 iPhone 或纯鸿蒙系统。

最新安装包为 [YingYu-v0.3.8-debug.apk](../../YingYu-v0.3.8-debug.apk)，大小 12,193,451 字节，约 11.6 MiB。与之前版本同签名，直接覆盖安装即可，不需要卸载或重新创建人物卡。已在连接的华为手机安装并完成夜间界面和前文切换验证。

0.3.8 的“接口设置”按 DeepSeek 文字聊天和 MiniMax 角色语音逐步说明，包含官方开放平台/文档入口、获取密钥、选择真实模型列表、保存配置与音色选择。当前接入方法见 NIGHT_AND_HISTORY_FIX；校验值与测试记录见 VALIDATION。以前的 HTTP 400 与分阶段验证记录见旧版日志。

## 首次配置

1. 在人物列表的“接口设置”里填聊天服务的 HTTPS 基础地址、模型 ID、API Key，点击保存。聊天基础地址不含 `/chat/completions`。
2. 若需要云端语音，在同页的语音区域单独填 MiniMax Key 并保存。没有语音 Key 也可以使用文字聊天。
3. 返回人物列表创建人物卡，填写角色名字、设定、简介、开场白和声音，保存后开始聊天。
4. 聊天页点“外观”可选择壁纸、调节玻璃通透程度与模糊、切换深浅文字。点击助手消息的“朗读”生成语音。

Key 只填在应用里，不用发送给开发者。云端语音试听和朗读会调用对应服务。

DeepSeek 用户可先点击“填入 DeepSeek 官方配置”，再“测试连接 / 获取模型”，从返回列表选模型并保存。已有 Key 可以留空保留；测试不会自动保存配置。若聊天出错，新版弹窗可复制服务端说明，发回该说明即可继续排查，无需发送 Key。旧会话的未完成用户消息可直接点“重试回复”。

## 更新与安装失败

- 以后更新应直接安装具有相同签名、且版本号不低于旧版的新包。保留开发签名是覆盖安装并保留数据的前提。
- 如果提示签名冲突，先联系开发者核对签名，不要立即卸载；当前尚无备份导出，卸载会删除人物与聊天记录。
- 若“解析包失败”，检查传输是否完整、后缀是否为 `.apk`、系统是否至少 Android 8.0，以及是否使用支持 Android APK 的系统。
- 若安装成功但打不开，记录手机型号、Android 版本、出现问题的步骤与系统提示，供后续定位。

安装后的玻璃视觉、音色和网络连接仍需结合具体手机验证，不能用桌面编译结果代替真机体验。
